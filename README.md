# Deep Learning-Driven User Profiles for Continuous, Non-Invasive Fraud Detection in Online Assessments

<!--Badges-->
![Repository Size][repository-size-shield] ![Issue Closed][issue-closed-shield]

Welcome to Deep Learning Fraud Detection for Online Assessment Repository!

This project aims to develop a machine learning-based fraud detection system for an online assessment platform. As online assessments become more prevalent, ensuring the integrity of user accounts is crucial.

The solution will employ advanced machine learning techniques to analyze user interaction data, determining whether the current user is the legitimate account holder.

You can run the codes in colab [here](https://colab.research.google.com/drive/1Z-bj288oLvlznIMzcokDo-8zgHqxBQHu?usp=sharing)
